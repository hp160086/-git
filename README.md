# 家门口便利店小程序原型

这是一个可点击的前端模拟版，用来先确认页面和下单流程，不需要 AppID、服务器或支付接口即可体验。

## 本地预览

在项目目录运行：

```powershell
python -m http.server 4173
```

然后打开 <http://127.0.0.1:4173/>。

## 已包含的页面

- 首页：搜索入口、常买分类、精选商品
- 分类：分类导航和商品列表
- 商品详情：规格、数量、店员配送说明
- 购物车/确认订单：地址、店员配送、配送费规则、微信支付/货到付款
- 我的订单：待接单、配送中、已送达等状态

## 当前业务规则

- 只配送店铺所在小区
- 店员配送
- 商品小计满 35 元免配送费
- 商品小计未满 35 元，配送费 5 元
- 支付方式先用模拟交互，后续接入真实微信支付
