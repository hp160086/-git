# 乐享便利店首页竹瀑背景嵌入方案

## 目标

将赤水竹瀑视觉从右上角单独的竹枝装饰和独立宣传卡，调整为首页顶部区域的背景内容，使品牌、搜索和配送提示自然叠加在竹瀑场景上，接近用户提供的参考布局。

## 已确认的范围

- 首页顶部背景覆盖品牌信息、搜索框和配送提示区域。
- 竹子与瀑布作为背景视觉，不再以单独卡片或独立按钮出现。
- 保留“乐享便利店”、赤水本地定位、搜索入口、店员配送和“满35元免配送费”等现有信息。
- 保留现有分类网格、精选商品和底部导航，不调整业务流程。
- 背景需要保持文字可读，搜索框和配送提示使用半透明或实色底保证可操作性。
- 其他页面继续使用简洁的顶部栏，右上角不放无功能装饰。

## 实现方式

1. 将首页顶部容器设置为相对定位，并使用现有 `assets/chishui-bamboo-waterfall-hero.png` 作为背景层。
2. 将品牌、搜索、配送提示放在背景层之上，通过背景定位和浅色遮罩控制对比度。
3. 删除首页独立的 `hero has-waterfall` 宣传卡，避免同一竹瀑素材重复出现。
4. 保留独立的行动按钮和配送文字，但将其作为顶部背景区域内的前景内容。
5. 在移动端 430px 宽度下重点检查：背景不裁掉关键竹子/瀑布、品牌和搜索不被遮挡、配送提示不溢出。

## 验收标准

- 首页首屏能看到融合在页面后方的竹子和瀑布，而不是右上角单独一张竹子卡片。
- 首页品牌、搜索、配送提示仍清晰可读并可点击。
- 分类、商品、购物车和底部导航现有交互不受影响。
- `node --check app.js` 和 `git diff --check` 通过。
- 本地手机尺寸预览无空白页、控制台错误或明显布局溢出。
